Once a [topic](/studio/help/topics) exists, link the artifacts it's about. You can do it from either side.

## From the topic's page

The topic's page has a **Linked artifacts** card, with every linked artifact listed and shown together on a map.

- **+ Add a new artifact linked here** opens the New artifact form with the link already set. Give the artifact its name and location and create it, and it's linked.
- **Or link one that already exists**: choose an artifact, add a note if it helps, and click **Link**. The list shows the artifacts you own (all artifacts, for an admin).

> **Example:** Adding six bike share stations. Open *Valley Bike Share*, click **+ Add a new artifact linked here**, name the first one *Bike share: Haigis Mall*, place its pin, and create it. Click the topic name in its **Topics** card to go back, and repeat for the next station. The topic's map fills up with a pin for each one.

## From an artifact's page

An artifact's page has a **Topics** card.

1. Under **Link to a topic**, choose the topic.
2. Add a **note** if it helps, like *Gold, 2013*.
3. Click **Link**.

The card then shows the topic, your note, and the topic's description. That description is what explorers will read on this artifact too.

## Notes

A note says how the topic applies to **this** artifact, in a few words (up to 200 characters).

- To **change** a note, click the pencil next to the topic on the artifact's page.
- Leave it empty if there's nothing particular to say.

## Unlinking

Click the **×** next to the topic on the artifact's page, or next to the artifact on the topic's page. Neither the artifact nor the topic is changed or deleted; only the link goes.

## Who can link

Linking changes what an **artifact's** page says, so you need to be able to change the artifact: it has to be yours, or you have to be an admin. You don't need to own the topic.

To link a classmate's artifact, ask them, or your instructor.

> **Note:** Linking or unlinking an approved artifact sends it back for review, like any other change to it.

## Seeing every artifact on a map

The topic's **Linked artifacts** card shows them all on one map, a pin for each. Click a pin to open that artifact. It's a quick way to check the set is complete, or spot one in the wrong place.
