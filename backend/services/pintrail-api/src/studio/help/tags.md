**Tags** are short words or phrases that say what an artifact is about: its themes. An artifact can have as many as it needs. People will be able to find artifacts by tag, and the [map](/studio/help/map) can show only the artifacts with a given tag.

> **Example:** The *Stormwater reuse for irrigation* system is tagged *stormwater* and *water*. The *Battery energy storage system* is tagged *energy* and *energy storage*.

## Adding and removing tags

On the Edit form, under **Tags**:

1. Type a tag and press <kbd>Enter</kbd> (or type a comma). It becomes a chip.
2. As you type, tags already used on other artifacts are suggested. **Pick a suggestion when it fits.**
3. Click the **×** on a chip to remove it.

## Good tags

- **Themes a visitor might look for:** *solar*, *stormwater*, *composting*, *energy storage*, *green building*, *biodiversity*.
- **Reused, not reinvented.** If *solar* already exists, use it rather than *Solar*, *solar power*, or *solar panels*. The suggestions are there for this.
- **Lowercase, singular when you can:** *rain garden*, not *Rain Gardens*.
- **A few, not dozens.** Two to five usually covers it.

## Tags to avoid

| Avoid | Why | Instead |
|---|---|---|
| *building*, *room* | That's the [kind](/studio/help/kinds). | Leave it to the kind. |
| *ILC*, *Old Chapel* | That's a name or a place. | Nest it in that building, or name it. |
| *interesting*, *cool* | Nobody searches for it. | A theme: *what* is interesting about it? |
| *LEED Gold 2013* | Too specific to group anything. | Link to the *LEED certification* [topic](/studio/help/topics), with the note *Gold, 2013*. |

## Tags versus topics

A tag is just a word. A [topic](/studio/help/topics) is a whole page, with its own description, links, and photos, shared by every artifact that links to it. If you find yourself wanting to explain a tag, it should probably be a topic. See [Kinds, tags, topics, or nesting?](/studio/help/tags-kinds-topics)

> **Note:** Up to 30 tags per artifact, each up to 60 characters.
