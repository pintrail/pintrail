A **trail** is a walk through artifacts in a set order, with a short note at each stop. Explorers follow trails in the Pintrail app: it shows the route on a map and tells them about each stop as they reach it.

> **Example:** *Where the rain goes*: start at the Integrative Learning Center green roof (*Look up: the roof is planted with sedum*), then the stormwater reuse system, then a rain garden across the plaza, ending at Campus Pond.

## What a trail has

- A **title** and a **description**: what the walk is about, how long it takes, where it starts.
- **Stops**: artifacts in walking order, each with an optional note, shown on a map with numbered pins joined by a line.
- **Who can see it**: private, anyone with the link, or public. See [Sharing a trail](/studio/help/sharing-a-trail).

## Things to know

- **Any artifact can be a stop**, whoever added it: a building or anything inside one. [Topics](/studio/help/topics) can't, because they aren't places.
- **Removing a stop doesn't change the artifact.** The trail just stops pointing at it.
- **Only approved artifacts appear in the app.** A stop whose artifact isn't approved yet is shown to explorers as *not available*, and the Studio warns you about it.
- **You change only the trails you made.** Everyone can see every trail in the Studio.
- **Only an admin can make a trail public.**
- Up to 200 stops per trail.
