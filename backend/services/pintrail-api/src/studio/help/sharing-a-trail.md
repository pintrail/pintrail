Every trail has a setting for **who can see it**. Choose it when you create the trail, or change it later with **Edit**.

| Setting | Who sees it | Use it when |
|---|---|---|
| **Private** | Only Studio authors. | You're still building it. |
| **Anyone with the link** | Anyone you give the **share code** to. It isn't listed in the app. | You want a few people to try it, or a class to walk it, before it's public. |
| **Public** | Everyone using the Pintrail app. It's listed in the app. | It's finished and checked. **Only an admin can choose this.** |

## The share code

When a trail is set to **Anyone with the link**, its page shows a **share code** with a **Copy** button. Give the code to the people who should see the trail.

Set the trail back to **Private** to stop the code working. If you set it to **Anyone with the link** again later, the same code works again, so links you already handed out keep working.

## Making a trail public

Only an admin (your instructor) can make a trail public. When yours is ready, with every stop approved, ask them. Until then, keep it private, or share it by link.

> **Tip:** Every stop's artifact must be approved, or explorers see that stop as *not available*. The trail's **Stops** card tells you how many aren't approved yet.
