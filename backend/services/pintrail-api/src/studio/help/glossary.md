| Term | Meaning |
|---|---|
| **Admin** | An author with full permissions: approves artifacts, makes trails public, manages accounts. Usually your instructor. |
| **Approved** | Checked by an admin. Only approved artifacts and topics appear in the app. See [Review, and what the app shows](/studio/help/review-and-the-app). |
| **Artifact** | Anything on campus worth stopping for: a building, a roof, a piece of equipment, an artwork. See [Artifacts](/studio/help/artifacts). |
| **Author** | Anyone with a Studio account: a viewer, editor, or admin. |
| **Child, nested artifact** | An artifact inside another one, like a green roof inside a building. |
| **Coordinates** | A location as two numbers, latitude and longitude, like `42.3910, -72.5259`. |
| **Description** | The text about an artifact: what it is, why it matters, how it works. See [Writing a good description](/studio/help/writing-descriptions). |
| **Draft** | Not yet submitted for review. Only Studio authors can see it. |
| **Editor** | An author who can add artifacts, topics, and trails and change their own. Students are editors. |
| **Explorer** | Someone using the Pintrail app on their phone. |
| **History** | The record of every change to an artifact. See [History](/studio/help/history). |
| **Inherited location** | Using the parent's location rather than its own pin. See [Location](/studio/help/location). |
| **Kind** | What sort of thing an artifact is: building, room, artwork, installation, rooftop, or other. See [Kinds](/studio/help/kinds). |
| **Link (source)** | A web page your facts come from, added in the Links card. See [Source links](/studio/help/links). |
| **Link (topic)** | The connection between an artifact and a topic, with an optional note. See [Linking artifacts to a topic](/studio/help/linking-topics). |
| **Media** | Photos and PDFs attached to an artifact. See [Photos and PDFs](/studio/help/media). |
| **Owner** | The person who added an artifact or trail, and the only editor who can change it. |
| **Parent** | The artifact another one is inside. |
| **Pin** | An artifact's location on the map. |
| **Public, private, anyone with the link** | Who can see a trail. See [Sharing a trail](/studio/help/sharing-a-trail). |
| **Ready for review** | Submitted, waiting for an admin to approve it or send it back. |
| **Sent back** | Returned by a reviewer with a note saying what to change. It's a draft again. |
| **Share code** | The code that opens a trail shared by link. |
| **Stop** | One artifact on a trail, with an optional note. |
| **Studio** | This website, where Pintrail content is written. |
| **Tag** | A theme an artifact is about, like *solar*. See [Tags](/studio/help/tags). |
| **Top-level artifact** | An artifact with no parent, like a building. It needs its own location. |
| **Topic** | A shared page many artifacts link to, like *LEED certification*. It has no place of its own. See [Topics](/studio/help/topics). |
| **Trail** | A walk through artifacts in order. See [Trails](/studio/help/trails). |
| **Viewer** | An author who can look but not change anything. |
