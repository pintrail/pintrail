At the bottom of every artifact's page, **History** lists every change ever made to it, newest first. Click **History** to open it.

## What it records

Each entry says **what** happened, **who** did it, and **when**:

| Entry | Example |
|---|---|
| Created | The name, kind, parent, and location it started with |
| Edited | *Description: from "..." to "..."*, for each field that changed |
| Tag added, Tag removed | *Tag added: solar* |
| Link added, edited, removed, or reordered | *Link added: umass.edu/facilities/utilities* |
| Photo or file added or removed | *Photo or file added: canopy.jpg* |
| Linked to topic, Unlinked from topic, Note changed on topic | *Linked to topic: LEED certification* (*Gold, 2013*) |
| Submitted for review, Withdrawn, Approved, Sent back for changes | *Sent back for changes*, with the reviewer's note |
| Owner changed | *Owner: from Sam to Paige* |
| Deleted, Restored | |

A topic's history also lists the artifacts linked to it and unlinked from it.

## Why it matters

- **Nothing is lost by editing.** If a change was a mistake, the history shows exactly what was there before, so you can put it back.
- **Credit is clear.** Everyone's name is on what they did.
- **Reviewers can see what changed** since they last approved something.

> **Note:** Changes made by a script or before authorship was recorded show as made by *system*.

The history can't be edited or deleted, by anyone.
